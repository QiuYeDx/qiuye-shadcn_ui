# MatrixEffect 旋转星旋径向衰减优化

## 问题

组件演示中的“旋转星旋”使用程序化 Canvas Source 绘制。每条旋臂原本以固定颜色和固定不透明度完整描边，导致从中心到外缘的信号强度基本一致。转换为 ASCII 或自定义图元后，旋臂末端仍和中心一样深，缺少静态星旋类似的空间层次。

## 调整

- 保留五条旋臂、现有配色、几何路径与旋转速度。
- 宽柔光层和窄核心层分别使用以星旋中心为原点的径向透明度渐变。
- 核心层在中心保持高强度，从中段开始平滑衰减，到旋臂末端降为透明。
- 同一条旋臂的两层描边复用一次 Path 构建，不增加额外动画循环或 React 状态。

## 行为边界

- 调整只影响 Demo 级“旋转星旋” Source，不改变 MatrixEffect 公共 API 或 Registry 安装内容。
- 时间、暂停、Reduced Motion 和离屏暂停仍由 MatrixEffect 核心调度。
