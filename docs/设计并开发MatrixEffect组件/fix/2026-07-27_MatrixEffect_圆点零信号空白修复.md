# MatrixEffect 圆点零信号空白修复

## 问题

圆点 Renderer 使用 `minimumRadius + radiusSpan * value` 计算半径。原公共默认值与站点示例都将最小半径设为大于 `0` 的数值，导致最终信号为 `0` 的格子仍会绘制很小的圆点，本应空白的区域因此呈现隐约的点阵纹理。

## 调整

- `createDotRenderer()` 与 `DotMatrixEffect` 的默认 `radiusRange` 由 `[0.35, 4]` 调整为 `[0, 4]`。
- 组件详情页快速预览和完整演示的最小半径调整为 `0`。
- 首页圆点示例的最小半径调整为 `0`。
- 同步更新基础用法、API 默认值、JSDoc 与开发设计文档。

## 行为边界

- 最终信号为 `0` 时，半径为 `0`，Renderer 通过现有的 `radius <= 0` 分支跳过绘制。
- 最大半径、光团速度、色彩和信号转换逻辑保持不变。
- 使用者仍可显式传入大于 `0` 的最小半径，以制作始终可见的规则点阵底纹。
